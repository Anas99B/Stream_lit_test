# Repository guide

This repository holds two independent projects:

- `app.py`, `Dockerfile`, `data/`, … — the Streamlit **Prompt Builder** (see README.md).
- `reels/` — the Remotion production for the **Arabic tech explainer reels**
  (style `arab-tech-explainer-v2`).

For any reel / episode / video work, load the reel instructions (which in
turn load the style and character guides):

@reels/CLAUDE.md
